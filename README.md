
# AI Branded Content Integration Agent

This Streamlit app takes a brand brief and `.docx` show concept files and uses OpenAI to generate integration scenes (active and passive). The output is a branded content proposal document.

## How to Use
1. Enter brand details in the form.
2. Upload one or more `.docx` story concept files.
3. Enter your OpenAI API key (get it at https://platform.openai.com/account/api-keys).
4. Click "Generate Proposal" to get a downloadable `.docx` proposal.

## File Format Example
```
Show Name- Adda in Gariahat
Themes- Friendship, Nostalgia, Self-Discovery, Urban Life
Episode 1- The Reunion: ...
Episode 2- Old Flames and New Troubles: ...
```
